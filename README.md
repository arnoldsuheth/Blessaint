# BLESSAINT · Streetwear Gospel

**BLESS** (bênção) **+ SAINT** (santa): onde a fé e o estilo se juntam para criar algo único.

Site oficial da marca BLESSAINT, criado do zero com **HTML, CSS e JavaScript** puros, como parte do meu projeto de estudos **Projeto Evolução Tech** (Ciência da Computação).

## Páginas
| Página | O que tem |
|---|---|
| `index.html` | Capa com efeito preto e branco + zoom e vitrine 360° interativa (arrastar para girar) |
| `drop-divine.html` | A coleção DROP DIVINE: cards com frente/costas e contorno de luz animado |
| `sobre.html` | A história da marca: a origem do nome, Bless, Saint e a cruz |
| `contato.html` | Instagram, loja e redes sociais |

## Destaques técnicos
- Layout responsivo (computador e celular), testado na tela do iPhone 16
- Vitrine 3D em JavaScript (`requestAnimationFrame`, arraste com o mouse ou o dedo)
- Animações em CSS: `@keyframes`, `transition`, `@property` (borda de luz) e `filter`
- HTML semântico: `header`, `nav`, `main`, `section`, `article`, `figure`
